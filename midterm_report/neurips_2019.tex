\begin{abstract}
Diffusion models generate images by learning to remove noise step by step.
In this project, we build four versions of diffusion models from scratch:
DDPM, DDIM, Latent DDPM, and Classifier-Free Guidance (CFG).
Each version improves on the last---faster inference, lower memory, or
better control over what gets generated.
We test on ImageNet-100 and aim for an FID score below 50,
where lower means the generated images look more like real ones.
\end{abstract}

\section{Introduction}

\subsection{Motivation and Objectives}

Diffusion models have become a leading approach for image generation.

This project has two main motivations. First, building diffusion models from scratch helps develop a deeper understanding of core components: noise scheduling, denoising networks, and inference procedures. Second, practical applications—such as data augmentation, medical imaging, and creative content generation—demand efficient and controllable implementations.

Standard DDPM is slow at inference time. DDIM addresses this with fewer steps. Latent diffusion reduces memory by operating in a compressed space. Classifier-Free Guidance (CFG) adds class-conditional control. Together, these variants cover the key tradeoffs in the field.

Our quantitative objective is to achieve a FID score below 50 on ImageNet-100 at $128 \times 128$ resolution. FID measures the similarity between generated and real image distributions, with lower values indicating higher quality.

Our qualitative objective is to implement four model variants in sequence: (1) DDPM, (2) DDIM, (3) Latent DDPM, and (4) CFG. This progression builds a complete picture of modern diffusion pipelines.

The primary beneficiaries are students, researchers, and practitioners who need clear, reproducible implementations for learning or deployment.

\section{Related Work and Background}

\subsection{Literature Review}

Ho et al.~\cite{ho2020denoising} proposed DDPM, which trains a U-Net to
iteratively denoise images. A key limitation is slow inference: generating one
image requires 1000 steps. DDIM~\cite{song2020denoising} fixes this by using a
deterministic update rule, cutting steps to 50--100 with no retraining needed.
To reduce training cost, Rombach et al.~\cite{rombach2022highresolution}
proposed running diffusion in the latent space of a VAE instead of pixel space.
Finally, Ho and Salimans~\cite{ho2022classifierfree} showed that a single model
can handle both conditional and unconditional generation by randomly dropping
class labels during training, eliminating the need for a separate classifier.

\subsection{Background}

We use FID~\cite{heusel2017gans} to evaluate generation quality. FID compares
the distribution of generated images to real images using features from an
Inception-v3 network. Lower scores mean better quality. It is the standard
metric, making it a natural choice for comparing our results.

\section{Methodology}

\subsection{Model Description}

We implement four diffusion model variants, each building on the last.
All use a U-Net as the denoising network.

\textbf{DDPM:} Our baseline. We add noise to images over 1000 steps,
then train a U-Net to reverse the process. Inference is slow since it
requires all 1000 steps.

\textbf{DDIM:} Same model as DDPM, but uses a deterministic update
rule at inference. This cuts generation down to 50--100 steps with
little quality loss.

\textbf{Latent DDPM:} We compress images into a smaller latent space
using a pre-trained VAE, then run DDPM there. This saves memory and
speeds up training.

\textbf{CFG:} We train one model for both conditional and unconditional
generation by randomly dropping class labels (10\% of the time). At
inference, we blend the two outputs to strengthen class-specific features.

\subsection{Dataset}

We use ImageNet-100 ($\sim$130k images, 100 classes), resized to
$128 \times 128$ and normalized to $[-1, 1]$. Random horizontal flips
are applied during training.

\subsection{Evaluation Metric}

We use FID to compare the distributions of real and generated images
via Inception-v3 features. Lower is better; we target FID $< 50$.

\subsection{Loss Function}

We minimize MSE between the noise predicted by the U-Net and the
true noise added during the forward process. For CFG, the class label
is randomly replaced with a null token 10\% of the time during training.

\subsection{Training Setup}

Each model is trained in two configurations: a base run
(lr $= 1{\times}10^{-4}$, batch size 64, 50 epochs) and a tuned run
with adjusted hyperparameters based on initial results. We log loss
and FID every 5 epochs and keep the best checkpoint.
